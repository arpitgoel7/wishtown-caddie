# Wish Town Caddie
Hole-by-hole strategy app for the AAA Titans at Jaypee Greens Wish Town. See `CLAUDE.md` (project context), `docs/LOGIC.md` (strategy model) and `TASKS.md` (batches).

Build: `python3 tools/build.py` → `dist/index.html`. Prepare a hole for mapping: `python3 tools/prep_hole.py NN`. Engine check: `node tools/test_engine.js [NN]`.
