# Wish Town Caddie
Hole-by-hole strategy app for the AAA Titans at Jaypee Greens Wish Town. See `CLAUDE.md` (project context), `docs/LOGIC.md` (strategy model) and `TASKS.md` (batches).

Build Hole 4 (v1): `python3 tools/build_h04.py` → `dist/wishtown-hole4.html`. Engine check: `node tools/test_engine.js`.
